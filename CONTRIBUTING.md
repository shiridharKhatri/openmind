# Contributing to OpenMind AI

Thank you for your interest in contributing to OpenMind! We welcome contributions from developers of all skill levels.

---

## How to Contribute

### 1. Reporting Bugs & Requesting Features
If you find a bug or have a feature idea:
1. Go to the [Issues](https://github.com/shiridharKhatri/openmind/issues) tab.
2. Search existing issues to make sure it hasn't been reported yet.
3. Click **New Issue** and describe the bug or feature clearly.

### 2. Submitting Pull Requests (Code Contributions)
To contribute code:
1. **Fork** the repository to your own GitHub account.
2. **Clone** your fork to your computer:
   ```bash
   git clone https://github.com/YOUR_USERNAME/openmind.git
   ```
3. Create a new branch for your feature or bugfix:
   ```bash
   git checkout -b feature/my-new-feature
   ```
4. Make your changes and verify that the project still builds:
   ```bash
   npm run build
   ```
5. Commit your changes with a clear message:
   ```bash
   git commit -m "feat: add my new feature"
   ```
6. Push to your branch:
   ```bash
   git push origin feature/my-new-feature
   ```
7. Go to the original OpenMind repository on GitHub and click **Compare & pull request** to submit your changes for review!

---

## Code of Conduct
Please be respectful and helpful to others in issues and pull request discussions. Let's build a great local AI tool together!
